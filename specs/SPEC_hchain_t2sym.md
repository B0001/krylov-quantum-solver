# SPEC: Symmetry-adapted T2 for the certified Hₙ bracket — the chem-3z8 PQG+T2 kill test at n = 10–12

**Status:** RESULTS_PENDING (chem-7ko). Amends [`SPEC_hchain_vsdp_bracket.md`](SPEC_hchain_vsdp_bracket.md) §7/§8 (R3).

---

## 1. Goal

chem-3z8 killed the PQG bracket (2.49 mHa/atom at n = 12) but could not evaluate PQG+T2 there: its two
large Sz-blocks are 2520 × 2520. Claim: adapting T2 to SU(2) (S² = 0) and chain reflection cuts the
largest block ~3× (2520 → 864 at n = 12) **without changing the SDP optimum**, so the certified
PQG+T2 lower bound becomes computable at n = 10 and 12 on a 16 GB laptop, and the pre-registered kill
(width > 1 mHa/atom at n = 12, vs FCI) can be evaluated.

## 2. Background and honest framing

- Spin adaptation of 2-RDM conditions is standard (Gidofalvi & Mazziotti 2005; DePrince's v2RDM uses
  it); this is that idea applied to make chem-3z8's certified bound reach n = 12. Not a new method.
- **Can claim:** a floating-point-rigorous lower bound on E0 for the Hamiltonian defined by the
  *reflection-symmetrized* float64 Löwdin integrals (h ← (h + PhP)/2, same for eri; changes FCI by
  < 1e-12 Ha), valid *if* that Hamiltonian's Sz = 0 ground state is a nondegenerate singlet. That
  premise is FCI-verified for every n reported (gap and ⟨S²⟩ recorded per row).
- **Cannot claim:** rigor without the singlet premise (beyond FCI size it is an assumption);
  anything at n > 12 (this spec does not run them); T2-tightness in other bases or geometries.

## 3. Approach

- **Premise → linear constraints on the RDM.** For a nondegenerate singlet, S⁺|ψ⟩ = 0 and P|ψ⟩ = ±|ψ⟩
  (P = mode permutation i → r−1−i, both spins). Imposed exactly: ⟨[S⁺, w]⟩ = 0 for every ≤2-body
  word w with Sz(w) = −1, and ⟨w⟩ = ⟨PwP†⟩ for every RDM parameter. Both are generated by the same
  normal-ordering routine as chem-3z8; nothing is hand-typed.
- **Block reduction.** With those constraints the T2 matrix is SU(2)×P invariant, so it is
  block-diagonal on (spin S, parity). Only highest-weight copies are kept: the S = 1/2 block is
  ker(ad S⁺) inside the M = +1/2 Sz-sector, the S = 3/2 block is the whole M = +3/2 sector; each is
  split by parity. M = −1/2, −3/2 and the S = 3/2 part of M = 1/2 are exact duplicates and dropped.
  Blocks at n = 4/6/8/10/12: 32/108/256/500/**864** (vs 88/306/736/1150/2520 Sz-only).
- **Exactness of the map.** Basis columns are built per reflection orbit of spatial labels by
  `fractions.Fraction` Gram–Schmidt, then scaled to primitive integer vectors, so each adapted entry
  X = QᵀMQ is an integer linear form of RDM parameters (A stays exact).
- **Rigorous bound carries over.** QᵀMQ ⪰ 0 for any Q, so the relaxation is valid for every state; the
  premise only adds equalities. Columns are mutually orthogonal, so the adapted blocks of one sector
  satisfy Σ tr X*ⱼ ≤ maxₐ‖qₐ‖² · tr M*_sector, and tr M*_sector is the exact (Nα, Nβ)-only trace. The
  bound uses that per sector group: `E0 ≥ bᵀy + Σ_g T_g · min(0, min_{j∈g} λ_min(Z_j))`.
- **Solver.** SCS 3.3 called directly on svec variables (`solve_scs`): cvxpy's canonicalization is
  avoided; column scaling leaves the row duals unchanged, so y feeds `certify` as before.
- **Reference:** exact FCI (`dmrg_reference.fci_energy`) on the same symmetrized integrals.

## 4. Public interface

```
vsdp_hchain.build(h1, eri, na, nb, t2="sym") -> dict      # adds groups: {name: (trace bound, blocks)}
vsdp_hchain.sym_basis(words, r) -> {+1: [(orbit, {word: int})], -1: [...]}
vsdp_hchain.sym_integrals(n) -> (h1, eri, (na, nb), e_nuc)  # reflection-averaged
vsdp_hchain.solve_scs(prob, **scs_settings) -> (value, y, status)
uv run python vsdp_hchain.py --ns 10,12 --sym             # certified PQG+T2sym rows + FCI gap / <S^2>
```

## 5. Acceptance criteria — `tests/test_hchain_t2sym_spec.py`

- **G0 — premise at H4.** Brute-force Fock-space ground state: ‖S⁺ψ‖ < 1e-10, gap > 1 mHa.
- **G1 — adapted maps vs brute force (H4).** At the exact ψ, every adapted T2 entry, singlet and
  reflection equality, contraction and the objective hold to 1e-10; each group trace ≤ its bound
  (= for unadapted blocks). Kills any sign/ordering error in ad S⁺, P or the integer bases.
- **G2 — sizes.** HW(S=½) dims sum to dim(M=½) − dim(M=3/2); S=3/2 dims sum to dim(M=3/2); largest
  adapted block ≤ dim(M=½)/2.5 (n = 4, 6).
- **G3 — same optimum, still valid (H4).** Adapted and Sz-only PQG+T2 SDP values agree to 2e-6 Ha;
  both certified bounds ≤ E0; adapted certified bound within 1e-5 Ha of E0.
- **Kill test (the finding, not a gate):** certified width per atom at n = 12 vs 1 mHa/atom.

## 7. Out of scope

- n = 14, 16 (DMRG upper bounds exist from chem-3z8; the singlet premise is then unverified).
- A custom boundary-point solver; multi-threaded eigensolves inside SCS.

## 8. Caveats

- **R1** as chem-3z8 (BLAS error model for the Cholesky bound).
- **R2 — premise.** The singlet/reflection equalities are only valid for a nondegenerate singlet.
  Verified by FCI here; if it failed, the equality rows would be wrong and the bound void.
- **R3 — trace bound.** Using maxₐ‖qₐ‖² (= 12 for S=½, 2 for S=3/2) instead of per-column norms costs up to that factor on the
  dual-infeasibility term only; it is visible as the certified − solver gap in §6.
