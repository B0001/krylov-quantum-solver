# Draft email to Prof. Malte Rösner — SUPERSEDED, do not send

**This draft is withdrawn.** It led with a ~29 % Hubbard-I "error" on the isolated Nb₃X₈ cluster.
A subsequent thermodynamic-limit check (coordination scan + DMRG chain, see
`notes/nb3x8_cluster_gaps.md`) showed that error is an **artifact of neglecting band broadening**:
restoring inter-dimer coordination collapses the exact gap back toward the Hubbard-I / cluster-DMFT
value (~600–650 meV vs Hubbard-I ~599). The result therefore *supports* the paper's method rather
than flagging a discrepancy, so the original email's premise no longer holds and it should not be
sent.

If any note goes out at all, it would be the corrected `notes/nb3x8_cluster_gaps.md` — a null /
confirming result (exact reference gaps for the clusters; Hubbard-I looks robust for the solid).
Whether that is worth an unsolicited email to the authors is doubtful; it is kept here as a record.
